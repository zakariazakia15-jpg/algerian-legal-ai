# بطاقة النموذج المرشح وخطة التخصيص

## الحالة

المسترجع الحالي لا يستخدم نموذجًا توليديًا. نُزّلت أوزان النموذج الأساسي محليًا في نسخة العمل الحالية، لكنها مستثناة من Git ولا تتضمنها النسخ المستنسخة من المستودع. لم يجر تدريب أو تقييم قانوني للنموذج، ولا تُحمّل الأوزان أو يُفعّل التوليد داخل التطبيق. توجد pipeline LoRA منفصلة في `scripts/train_lora.py`؛ وجودها لا يعني أن النموذج دُرّب، ولا يحوّل RAG إلى fine-tuning.

## النموذج المختار للتجربة

المرشح الصغير هو `Qwen/Qwen2.5-1.5B-Instruct` (نحو 1.54 مليار parameter)، ضمن نطاق 1-4B المطلوب. بطاقة النموذج تعلن دعم العربية والفرنسية ضمن اللغات المدعومة. إنه نموذج عام instruction-tuned؛ لا يحتوي معرفة مثبتة بالقانون الجزائري ولا يجوز وصفه بأنه نموذج قانوني.

ثبتنا revision المصدر `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`. ملف الترخيص في هذا revision هو Apache-2.0؛ يجب الاحتفاظ بنسخة الترخيص والإشعارات عند توزيع الأوزان أو المشتق، ومراجعة الترخيص والقيود وقت أي نشر:

- بطاقة مثبتة: <https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct/tree/989aa7980e4cf806f80c7fef2b1adb7bc71aa306>
- الترخيص المثبت: <https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct/raw/989aa7980e4cf806f80c7fef2b1adb7bc71aa306/LICENSE>

## الأوزان المحلية

في نسخة العمل التي جهّزت هذا الملف، توجد الأوزان في `models/base/Qwen2.5-1.5B-Instruct/`، بحجم 3,087,467,144 بايت لملف `model.safetensors`. بصمته SHA-256 هي `dd924a11b4c220f385b51ffa522daea7c9f3d850e31b162bb5661df483c6d3ee`، المطابقة لبيانات الملف في revision المثبت أعلاه. تحققت أيضًا من ملفات الإعداد والترميز والترخيص. هذا المسار مستثنى من Git عمدًا؛ لا ترفع ملفات الأوزان إلى المستودع أو تضفها إلى commit. بعد clone جديد، لن يوجد هذا المجلد إلا إذا نزّل المستخدم الأوزان محليًا.

لتحميل النموذج الأساسي محليًا لأغراض التجربة فقط بعد تثبيت التبعيات الاختيارية (`python -m pip install -e ".[finetune]"`)، يمكن استخدام `transformers` مع منع أي تنزيل تلقائي:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_path = "models/base/Qwen2.5-1.5B-Instruct"
tokenizer = AutoTokenizer.from_pretrained(model_path, local_files_only=True)
model = AutoModelForCausalLM.from_pretrained(model_path, local_files_only=True)
```

هذا يحمّل نموذجًا عامًا غير مدرّب قانونيًا؛ ولا يدمجه في التطبيق أو يجعله مصدرًا لإجابة قانونية. الحمل الكامل يستهلك ذاكرة إضافية، وقد لا يناسب الأجهزة محدودة الذاكرة. في بيئة التطوير التي فُحصت أثناء مهمة التنزيل، لم تكن `transformers` و`safetensors` مثبتتين، لذلك لم يُجر اختبار تحميل أو استدلال.

## ما أُعدّ وما لم يُنجز

- `scripts/train_lora.py` يطبّق LoRA SFT على أمثلة موثقة ومجازة، ويخفي prompt tokens من loss، ويستخدم validation لاختيار أفضل checkpoint. المجموعة test لا تدخل التدريب.
- `src/dz_legal_ai/training_data.py` يتحقق من الولاية DZ، لغة ar/fr، موافقة المراجع، الترخيص، إسناد كل إجابة إلى corpus محلي موثق، وتقسيم المستندات بين train/validation/test لمنع تسرب نص القانون بين التقسيمات.
- `scripts/evaluate_before_after.py` يولّد مخرجات أساس/adapter على test محليًا ويحفظ بطاقات لمراجعة بشرية؛ لا يحسب درجة قانونية تلقائيًا.
- **لا توجد أمثلة تدريب SFT موافق عليها في المستودع، ولا corpus واسع، ولا adapter مدرّب، ولا نتائج قبل/بعد.** يتضمن corpus التجريبي نصين فرنسيين فقط (الأمر 03-05 ونص دستوري منشور سنة 2020)، وحالة نفاذهما غير متحققة؛ لا يمكن منهما إنشاء تقسيمات قانونية مستقلة أو ادعاء شمول.

لتثبيت optional dependencies وتشغيل pipeline على موارد محلية راجع `docs/TRAINING.md`. لا تُرسل البيانات إلى مزود سحابي. يُرفض تشغيل التدريب على CPU افتراضيًا، ولا تبدأ أي معالجة سحابية دون موافقة صريحة.

## حدود الاستخدام

لا يُفعّل التوليد في التطبيق قبل توفر corpus متنوع ومراجع قانونيًا، ومجموعة SFT مرخصة، واختبار مستقل للحداثة والتغطية والامتناع، ومراجعة قانونية. يجب أن يقتصر كل prompt وبيانات التدريب والاختبار والاسترجاع على قانون الجزائر. يبقى RAG مصدر الإجابات والإحالات؛ لا يجوز لـ fine-tuning اختراع نص أو مرجع أو نفاذ، ويجب الامتناع عند غياب دليل جزائري.
