# بيانات التدريب

لا توجد هنا أمثلة train/validation/test. هذه المجموعة غير جاهزة للتدريب، ولا يقدّم النص الموجود في `data/seed/` وحده تقسيمات قانونية مستقلة أو نطاقًا كافيًا.

احتفظ بملفات `train.jsonl`, `validation.jsonl`, و`test.jsonl` محليًا فقط؛ Git يستثنيها. اتبع مخطط provenance والمراجعة القانونية في `docs/TRAINING.md`. لا تُنشئ أسئلة/أجوبة قانونية آليًا، ولا تضف إلا نصوصًا جزائرية موثقة، مرخصة لإعادة الاستخدام، ومراجعة من مختصين. يمنع إدراج قوانين دول أخرى أو بيانات قضايا/أشخاص.
